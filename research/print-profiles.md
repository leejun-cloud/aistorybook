# POD 출판 프로파일 규격 (교보 바로출판 POD · 부크크)

파트 3(조판)·파트 4(표지·인쇄) 구현의 정본 참조 문서.
사용자 확정 방침: **출판 표지는 앞표지+책등+뒷표지 랩 형태 필수. 책등은 페이지 수만으로 계산하지 않고 제본 방식+종이 종류+페이지 수를 함께 입력받아 계산한다.**

---

## 1. 책등(세네카) 두께 계산

### 1.1 기본 공식 (무선제본, 양면 인쇄)

```
책등(mm) = (총 페이지 수 ÷ 2) × 종이 1장 두께(mm) + 제본풀 여유
```

- 제본풀 여유: **+1mm** (무선제본 접착제 두께 — 인쇄업계 통용)
  (일부 계산기는 +0.5mm를 쓰므로 프로파일별 설정값으로 둔다. 기본 +1mm)
- 반올림: **0.5mm 단위** (3.2→3, 3.4→3.5, 3.7→3.5, 3.8→4)
- 단면 인쇄면 ÷2를 하지 않는다.
- 면지가 있으면: `(총 페이지 수 + 면지 장수 × 4) ÷ 2 × 종이 두께 + 여유`

### 1.2 제본 방식별 분기 (사용자 확정 요구사항)

| 제본 방식 | 책등 계산 | 비고 |
|---|---|---|
| 중철 (16~32p) | 책등 없음 (0mm) | 표지 = 앞+뒤 2면만. 책등 텍스트 불가 |
| 무선제본 (32~80p+) | 기본 공식 | POD 표준. 교보 POD는 무선제본만 지원 |
| 양장(하드커버) | 기본 공식 **+5mm** (보드+제본 여유) | 후속 프로파일 |
| 보드북 | 페이지 자체가 판지 — 별도 계산 (장수 × 판지 두께) | 후속 프로파일 |

### 1.3 종이 1장 두께 기본값 (설정 가능 계수)

| 내지 종이 | 1장 두께(mm) | 비고 |
|---|---|---|
| 백색모조 80g | 0.095 | 흑백 내지 일반 |
| 백색모조 100g | 0.115 | 컬러 그림책 일반 |
| 이라이트 80g | 0.106 | 가볍고 도톰 |
| 스노우지 100g | 0.09 | 컬러 사진 인쇄 |
| 아트지 150g | 0.12 | 고급 컬러 |

> 수치는 인쇄소 공용 계산기 기준 근사값. **프로파일 JSON에 계수로 저장하고 하드코딩하지 않는다** — POD사가 공지하는 실측값으로 갱신 가능해야 함.
> 예시 검산: 32p 그림책 × 0.15mm 두꺼운 용지 = 32÷2×0.15 = 2.4mm → 책등 2~3mm는 책등 제목 인쇄가 어려움 → **책등 폭 < 5mm면 책등 텍스트를 자동 생략**하고 사용자에게 알린다.

## 2. 표지(랩) 크기 계산 — 부크크 공식 규격 체크 코드에서 직접 추출

부크크 자동 규격체크 페이지(bookk.co.kr/auto-size-preview.html)의 실제 계산 로직:

```
판형 프리셋: 46판 127×188 / A5 148×210 / B5 182×257 / A4 210×297 (mm)
날개(flap): 있으면 좌우 각 100mm
재단여백(bleed): 3mm

표지 전체 폭 = 판형폭 × 2 + 책등 + (날개 시 100 × 2)
표지 전체 높이 = 판형 높이
구성(왼→오): [왼날개] 뒷표지 | 책등 | 앞표지 [오른날개]
```

- **책등 두께는 사용자가 직접 입력하는 필드** (부크크 도구 기준) — 우리 프로그램은 §1 공식으로 자동 계산해 채워주되 사용자가 수정 가능하게 한다.
- 그림책 정사각 판형(210×210 등)은 부크크 표준 프리셋에 없음 → **부크크 지원 판형 중 선택 유도** (A5·B5 추천) 또는 사용자 지정 판형 여부를 POD사에 확인 후 진행 안내.

## 3. 교보 바로출판 POD 제약

- **무선제본만** 지원 (소량 인쇄).
- 표지 재질 선택지: 아르떼 210g / 스노우 250g / 아트지 250g / 아트지 150g.
- 상세 판형·여백 규격은 입점 가이드 문서 기준 — 구현 시 프로파일 JSON에 채울 것.

## 3.5 판형 프리셋 — 조판에서 페이지 크기 결정 시 참조 (명명된 프로파일)

사용자 확정 방침: **샘플 책 크기 사례를 "교보1", "부크크1" 식으로 제목을 붙여 제공**해, 나중에 해당 POD사로 출간할 때 바로 매칭되게 한다.

### 부크크 지원 판형 (공식 규격체크 도구 기준 — 이 4종만 확정 지원)

| 프로파일명 | 판형 | 크기(mm) | 그림책 적합성 |
|---|---|---|---|
| **부크크1** | A5 (국판) | 148×210 | 소형 그림책·문고형. 세로형 |
| **부크크2** | B5 (46배판) | 182×257 | **그림책 추천 기본값** — 판면이 넓어 삽화 살림 |
| **부크크3** | A4 (국배판) | 210×297 | 대형 그림책·워크북 겸용 |
| **부크크4** | 46판 | 127×188 | 미니북 |

### 교보 바로출판 POD (무선제본 전용)

| 프로파일명 | 판형 | 크기(mm) | 비고 |
|---|---|---|---|
| **교보1** | A5 | 148×210 | 표지: 스노우250g/아르떼210g/아트지 선택 |
| **교보2** | B5 | 182×257 | 그림책 추천 |
| **교보3** | 신국판 | 152×225 | 단행본 표준 |

> 교보 POD의 확정 지원 판형 목록·PDF 상세 규격은 공개 웹에서 확인 불가 — **입점 시 공식 가이드로 프로파일 JSON을 갱신**한다(구현은 프로파일 추가만으로 대응 가능해야 함).

### 일반 그림책 판형 참고 (POD 외 인쇄소용 후속 프로파일)

| 이름 | 크기(mm) | 비고 |
|---|---|---|
| 정사각 그림책 | 210×210 | 유아 그림책 관행 판형. 부크크·교보 표준엔 없음 — 일반 인쇄소용 |
| 4×6배판 | 188×257 | 전통 그림책·교재 판형 |
| A5 변형(신국판) | 152×225 | 이야기책형 |

**조판 규칙**: 페이지 크기는 반드시 위 프로파일 중 하나를 선택해 결정한다. 자유 크기 입력은 "사용자 지정(일반 인쇄소)" 프로파일에서만 허용하고, POD 프로파일 선택 시 해당 사의 판형·표지 재질·제본 방식 제약이 함께 잠긴다.

## 3.6 내지 여백 규격 (부크크 권장 기준)

- 위/아래 여백: **20~40mm** (사용자 기억의 "3cm 여백"이 이 범위 — 기본값 상하 30mm 권장)
- 좌/우(바깥) 여백: **20~25mm**
- 안쪽(제본) 여백: 바깥 여백 **+3mm** (200페이지 초과 시 +5mm) — 무선제본 말림 보정
- 중철제본: 안쪽 = 바깥 동일
- 재단 안전 여백: 재단선 안쪽 최소 **5mm**에만 글·핵심 요소 배치

> 단, 위 수치는 **텍스트 중심 단행본 기준**이다. 그림책의 풀블리드 삽화는 여백 규칙의 예외(재단선+3mm까지 채움)이고, **글 슬롯**에만 위 여백 규칙을 적용한다. 조판 템플릿(L01~L10)의 글 영역이 이 여백 안에 있는지를 사전검사 항목에 포함할 것.

## 4. 조판(내지)에 반영할 인쇄 제약

1. **재단여백 3mm** — 모든 페이지 사방. 풀블리드 그림은 재단선까지 채우고, 글·핵심 요소는 재단선 안쪽 안전영역(최소 5mm 권장)에.
2. **제본선(무선제본 안쪽) 여백** — 펼침면에서 안쪽 여백을 바깥보다 크게. 제본선 근처 10mm에는 얼굴·핵심 소품·글을 두지 않는다 (풀 제본으로 안쪽이 말려 들어감).
3. **표지 안쪽 백지 규칙** — 무선제본은 표지 안쪽의 책등 접착부와 그 양옆 3~5mm에 인쇄·코팅을 넣지 않는다 (접착력 확보). 표지 PDF 생성 시 안쪽면을 출력한다면 이 영역을 백지로.
4. **펼침면 이미지** — 좌우 페이지에 걸치는 그림은 제본선에서 각 3~5mm씩 이미지가 겹치도록 여유를 두면 재단·제본 오차에 강하다.
5. **해상도** — 인쇄 300dpi 기준. Gemini 출력 1024×1024는 210×210mm에서 약 124dpi → **업스케일 단계 필수** (PRD §3.1의 업스케일 잡이 이 기준을 목표로).

## 5. 프로파일 데이터 모델 (구현 지침)

```json
{
  "id": "bookk-a5-softcover",
  "vendor": "bookk",
  "trim": { "width": 148, "height": 210 },
  "bleed": 3,
  "binding": "perfect",            // saddle | perfect | hardcover | board
  "spineFormula": {
    "glueAllowance": 1.0,
    "hardcoverExtra": 5.0,
    "roundTo": 0.5,
    "minSpineForText": 5.0
  },
  "interiorPapers": [
    { "name": "백색모조 100g", "sheetThickness": 0.115 },
    { "name": "이라이트 80g", "sheetThickness": 0.106 }
  ],
  "coverPapers": ["스노우 250g", "아르떼 210g"],
  "flapWidth": 100,
  "innerMarginMin": 15,
  "safeArea": 5
}
```

사용자 흐름: **제본 방식 선택 → 내지 종이 선택 → 페이지 수(자동) → 책등 자동 계산(수정 가능) → 랩 표지 캔버스 생성**.
